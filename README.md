# 🚀 Rencana Proyek: Aplikasi POS Kasir Kafe

Proyek kerja kelompok untuk membangun aplikasi kasir digital berbasis web menggunakan **Node.js, React, dan JavaScript**.

## 👥 Anggota Tim & Pembagian Tugas
* **[FAISHOL]**: Fokus ke Frontend (React UI, Keranjang Belanja, & State Management).
* **[FAISHOL]**: Fokus ke Backend (Node.js/Express, API Menu, & Database).
* **[UMAIR]**: Fokus NGOPI.

## 🛠️ Rencana Fitur Aplikasi
1. **Manajemen Menu**: Menampilkan daftar makanan/minuman dengan filter kategori.
2. **Sistem Keranjang**: Bisa menambah, mengurangi, dan menghitung total harga secara otomatis.
3. **Riwayat Transaksi**: Menyimpan data penjualan ke database server.
